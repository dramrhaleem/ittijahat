# صفحة تسليم أداة كتابة مباحث الرسالة — الإصدار الثالث

موقع ثابت (ملف واحد `index.html` + تنسيق + ملفات التنزيل). لا يحتاج أي بناء ولا خادم.

## الرفع على GitHub Pages (خمس خطوات)

1. افتح github.com وأنت مسجّل الدخول بحساب `dramrhaleem`، واضغط **New repository**.
   - الاسم: `ittijahat`
   - النوع: **Public** (لازم عشان الصفحة تشتغل مجانًا)
   - اضغط **Create repository**.
2. في صفحة المستودع الفاضية اضغط **uploading an existing file** (أو **Add file ← Upload files**).
3. اسحب **محتويات** هذا المجلد كلها إلى الصفحة (الملفات `index.html` و`README.md` و`.nojekyll` والمجلدين `assets` و`files`) — مش المجلد نفسه، محتوياته. استنّى لحد ما الرفع يخلص (أكبر ملف ٩ ميجا).
4. اكتب في خانة الرسالة: «الإصدار الثالث» واضغط **Commit changes**.
5. من أعلى المستودع: **Settings ← Pages**. تحت **Build and deployment** اختر:
   - Source: **Deploy from a branch**
   - Branch: **main** و **/ (root)** ← **Save**.

بعد دقيقة أو اثنتين الصفحة تكون شغّالة على:

**https://dramrhaleem.github.io/ittijahat/**

## بدائل الاسم

- لو عايز الرابط أقصر بدون اسم مستودع: سمِّ المستودع `dramrhaleem.github.io` (ده مستودع الصفحة الرئيسية للحساب) فيبقى الرابط `https://dramrhaleem.github.io/` — بس ده يستهلك صفحة الحساب الرئيسية.
- لو هتشتري نطاقًا خاصًّا لاحقًا: من **Settings ← Pages ← Custom domain** اكتب النطاق، وأضف سجلات DNS اللي جيتهب هيطلبها. الملفات لا تحتاج أي تعديل لأن كل الروابط نسبية.

## التحديث لاحقًا

أي ملف جديد يتحط في مجلد `files/` ويتضاف له سطر في `index.html`. لو الصفحة اتولّدت تاني من الأداة، ارفع `index.html` الجديد مكان القديم بنفس الطريقة (Add file ← Upload files ← Commit).

## ملاحظات

- ملف `.nojekyll` ضروري: بيخلّي جيتهب يقدّم الملفات كما هي من غير معالجة.
- الخطوط (Amiri وIBM Plex Sans Arabic) مضمّنة في `assets/fonts/` برخصة OFL؛ الصفحة لا تحمّل شيئًا من خدمات خارجية.
- أسماء الملفات في `files/` لاتينية عمدًا لسلامة الروابط، لكن عند التنزيل يحصل الزائر على الاسم العربي الأصلي.
